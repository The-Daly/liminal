# V0.1 Player Journey

This defines the first 30-60 minutes of play for the graybox prototype. It does not change locked systems.

## First Session Flow

1. Player starts in the faction hub with a temporary faction selector.
2. Player chooses M.E.G., B.N.T.G., or Clippers and receives the matching starter loadout.
3. Quartermaster placeholder explains the first objective: recover supplies from Level 1 and return alive.
4. Player visits the personal room and sees safe storage plus a relic display placeholder.
5. Player deploys through a sealed service corridor into Level 1 Service Halls.
6. Player loots containers for Movie Tickets, Almond Water, batteries, scrap, chalk, and a rare relic.
7. Sanity drains during the run; Almond Water restores sanity.
8. Flicker Stalker patrols the Flicker Corridor and can chase/kill the player.
9. Player extracts through the stable service door or hidden ticket booth exit.
10. Player returns to the personal room, stores loot, or contributes to the hub project board.
11. A second run should demonstrate death: carried inventory is lost, personal storage remains safe.

## Faction Starter Uses

- M.E.G.: Entity Scanner highlights Flicker Stalker clues and supports archive-office flavor.
- B.N.T.G.: Crowbar supports salvage/trader-kiosk flavor and future crate interactions.
- Clippers: Camcorder and chalk support hidden route and hidden extraction flavor.

## Movie Ticket V0.1 Uses

- Basic trader currency placeholder.
- Required item for the hidden ticket booth extraction.
- Contribution item for the first hub project.
- Score/reward readout after extraction.

## Trader And Quartermaster

- The trader can sell Almond Water and batteries for Movie Tickets in V0.1.
- The quartermaster gives starter loadouts and points the player toward the deployment gate.
- Both can be static interactable placeholders until dialogue and economy systems exist.

## Hub Project Board

- First project: Signal Lamp Project.
- Required contribution: Movie Tickets and scrap.
- Visible unlock: a working signal lamp near the deployment gate.
- Mechanical effect can be deferred; V0.1 only needs visible proof that contribution changes the hub.

## Relic Display

- Relic-Class items can be stored safely in personal storage.
- Displayable relics appear in a personal room placeholder case.
- The first relic is `relic_golden_admit_one_ticket`.
