# Serious Frontend Direction

## Intent

The frontend should feel like a serious Backrooms operations interface, not a generic game launcher.

The mood target is:

- institutional
- tense
- decayed
- procedural
- faction-aware

The inspiration is the weight and seriousness of early extraction-game frontends, but the visual identity must remain original to Liminal Dominion.

## Title Shell

The title shell should feel like entering a monitored threshold space.

Use:

- dim service lighting
- distant fluorescent hum
- M.E.G. archive signage language
- B.N.T.G. logistics labeling
- Clippers route-mark residue
- subtle movement in the background scene rather than bright promotional spectacle

Avoid:

- heroic splash art
- glossy sci-fi dashboard styling
- playful or neon-heavy UI
- generic white-text-on-black placeholder menus

## Flow Priority

The frontend must communicate the following order clearly:

1. choose a server realm
2. review or create a server-bound character
3. commit to a faction on that realm
4. enter the main operations menu
5. deploy into the playable loop

## Information Hierarchy

The most important persistent-world information should always be visible:

- realm name
- realm type: official or community
- region
- next wipe date
- faction lock status
- faction population snapshot
- current character callsign

## Character Presentation

Character presentation should stay restrained for now.

Use:

- a standing operator preview
- minimal preset swaps
- faction outfit identity
- a quiet, grounded presentation angle

Do not build:

- full face sculpting
- deep body sliders
- vanity-first fashion browsing
- hero-shot presentation

## Main Menu Sections

The first serious menu should expose:

- Character Overview
- Deploy
- Stash
- Faction Status
- Signal Lamp Project
- Trader Access
- Server and Wipe Status
- Settings

These should read like operational destinations, not like casual tabs.
