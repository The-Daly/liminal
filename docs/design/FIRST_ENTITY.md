# First Entity — Flicker Stalker

## Role

Prototype monster for Version 0.1.

## Behavior

- Patrols the Flicker Corridor.
- Reacts to loud sound.
- Chases when player is detected.
- Detection increases during flicker events.
- Low player sanity increases false sightings.
- Scanner/camcorder can detect clues before direct sighting.

## MVP Implementation

Start with:
- Patrol.
- Perception radius.
- Chase.
- Attack.
- Return to patrol if player escapes.
